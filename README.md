# Inventory Management System

A full-stack **Inventory Management System** built using **Angular v14** for the frontend and **NestJS** for the backend. This system allows users to manage inventory including categories, products, stock levels, and more.

## 📁 Project Structure


---

## ⚙️ Tech Stack

- **Frontend:** Angular v14, TypeScript, RxJS, SCSS
- **Backend:** NestJS, TypeScript, Mysql , Type ORM 
- **Communication:** REST API

---

## 🚀 Features

- Product management
- Stock tracking
- Inventory reports
- Responsive admin dashboard

---

## 🧩 Prerequisites

Ensure you have the following installed:

- **Node.js** (v16 or later recommended)
- **npm** (v8 or later)
- **Angular CLI** (v14)
- **NestJS CLI**
- **Mysql**
